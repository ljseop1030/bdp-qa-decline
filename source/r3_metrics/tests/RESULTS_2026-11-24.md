# v0.3 두 선정안 호스트 검증 - 2026-11-24

## 범위

- 기본 `category`: A12/B12, 24사이트, 1,512행.
- 대안 `size-matched`: A12/B12, 24사이트, 1,512행.
- 재현 `legacy130`: A118/B12, 130사이트, 8,190행.
- 두 24사이트 입력의 합집합: 34개. B12는 동일하다.

## 수행한 검사

Windows Python 3.13 호스트에서 `python -m unittest discover -s tests -p 'test_*.py'`를 실행해 52개 검사가 통과했다.

검사는 프로필별 목록·분류 근거·해시·예상 행 수, 기본 활성 파일과 현재안 사본의 일치, 두 프로필의 기존 로컬 기준값 1,512행 완전성, 두 선정안의 완료 영수증과 선택 사이트 전달, 부분 실행의 전체 통계 발행 금지, 범위 밖 사이트 거부, 입력·구현 변경 감지, Hive 옵션 전달과 기존 정확 순위합 검정을 포함한다.

완료 테스트의 외부 Spark/HDFS 호출은 대역으로 수행했다. 기존 로컬 기준 데이터 검사는 실제 보관된 집계값에 대한 스키마·키·기간·비율 유효성 검사이며 새로운 VM 계산이 아니다.

## 미수행

이번 변경에 대한 Python 2.7 실제 VM 실행, Spark/Hive 집계, 24사이트 원본 입력의 처리 성능 및 R2/R4 연동 검증은 아직 수행하지 않았다. `tests/test_vm.sh --scope <선정안>`으로 실제 환경에서 검증하고 새 `validated.json` 및 비교 결과를 남겨야 한다. 과거 v0.2의 VM 성공 기록을 v0.3 성공 기록으로 해석하지 않는다.
